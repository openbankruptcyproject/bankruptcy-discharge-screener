# Contributing

Thank you for your interest in contributing to the Bankruptcy Discharge Screener.

## Ways to contribute

- **Report data issues** — If you find a case that should be flagged but isn't (or vice versa), open an issue with the case number and district.
- **Add district data** — We welcome verified case data from any federal bankruptcy district.
- **Improve the screener** — Bug fixes, UI improvements, accessibility enhancements are all welcome.
- **Translate** — Help make the screener accessible in more languages (Spanish translations are in progress).
- **Spread the word** — Share the tool with attorneys, legal aid organizations, law school clinics, or anyone who works with bankruptcy filers.

## How to submit changes

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request with a clear description

## Data standards

- All case data must be verifiable through public court records (PACER, RECAP, or CourtListener)
- Never include debtor names, SSNs, or other PII
- Attorney names from public court records are acceptable in analysis but not in the screener display

## Code of conduct

Be respectful. This project exists to help people navigate the bankruptcy system. We welcome contributors of all backgrounds and experience levels.
